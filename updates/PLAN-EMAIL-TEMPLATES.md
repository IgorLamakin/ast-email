# План доработки стандартных email-шаблонов «АСТ»

Переработка 5 стандартных писем под цели: получение заявок по теме письма,
привлечение клиентов, поднятие имиджа компании. Единый дизайн в фирменных
цветах (светло-серый + зелёный), с указанием брендов с логотипами.

Источники брендов и фактуры: `instrument/Презентация_ООО_АСТ.pdf`, сайт
https://astkip.ru/, открытые источники для логотипов.

---

## 1. Исследование рынка и конкурентов

- Сегмент: КИПиА/АСУТП (поставка + проектирование + шкафы + монтаж/ПНР + SCADA).
- Конкуренты: **каталог-дистрибьюторы** (КИП-Сервис: ELHART, VALMA, ONDO и др. —
  сильны магазином, слабы в инжиниринге), **производители** (ОВЕН, Элемер),
  **интеграторы**.
- Вывод: УТП АСТ — «полный цикл» одним партнёром; письма короткие, экспертные,
  с брендами (доверие), цифрами (доказательность) и одной целью — заявка.

Фактура astkip.ru: направления — комплексная поставка / проектирование /
разработка АСУТП / монтаж и ПНР; преимущества — персональный подход,
оперативность, складские запасы, техподдержка; контакты: Краснодарский край,
г. Краснодар, ул. Российская 208/1, +7 (900) 272-06-68, krd@astkip.ru.

## 2. Бренды в письмах

- **«Наши бренды»** (основные, вверху): официальные бренды АСТ — из
  `instrument/Презентация_ООО_АСТ.pdf` и astkip.ru (уточнить фактический
  список при реализации).
- **«Бренды под заказ»** (в конце письма, заказные позиции): Siemens · ABB ·
  Schneider Electric · Phoenix Contact · Endress+Hauser · WIKA · IFM · Balluff ·
  Sick · Emerson · Yokogawa · Omron.
- **Логотипы — обязательно картинками** (обе группы). Файлы берём из открытых
  источников (PNG, прозрачный фон, ≈8–40 КБ), кладём в
  `backend/email_templates/logos/`, встраиваем в письмо как `data:image/png;base64`
  (механизм уже есть — `_inline_local_images` в `backend/main.py`), чтобы
  логотипы гарантированно отображались.

## 4. Единая дизайн-система

HTML-таблицы, inline CSS, 600px, адаптив, шрифт Segoe UI/Arial, без внешних
картинок (всё — data-URI). Блоки: Preheader → Header (АСТ + слоган
«Интеллект в каждом компоненте» + зелёная линия) → `{{ greeting }}` → Hero
(оффер + 3 цифры) → **«Наши бренды» (лого)** → основной блок →
доказательства → CTA `mailto:{{ sender_email }}?subject=…` + «просто
ответьте» → **«Бренды под заказ» (лого)** → Подпись (по визитке) → Футер.

## 5. Подпись (по визитке, саму визитку не вставляем)

«С уважением,» → {{ full_name }} → {{ position }} → {{ company }} «АСТ»
(с зелёной точкой) → тел./email/сайт → тонкая зелёная линия + слоган.

## 6. По шаблонам (тема / цель / CTA)

1. Общий обзор — «Комплексная автоматизация производства: от датчика до
   АСУТП»; + «Наши бренды» + мини-кейс; CTA «Получить консультацию инженера».
2. Поставка КИПиА — «Поставка КИПиА: подберём и привезём, КП за 24 часа»;
   категории ↔ бренды, преимущества; CTA «Запросить коммерческое предложение».
3. Шкафы — «Шкафы управления под ключ: проект, сборка, ПНР»; типы шкафов,
   комплектация (бренды), гарантии, бонус «бесплатно 3D-проект и спецификация»;
   CTA «Рассчитать стоимость шкафа».
4. Инжиниринг и ПО — «SCADA и автоматизация под ключ»; этапы 1–5, платформы
   (Siemens TIA/WinCC, CoDeSys, ОВЕН…); CTA «Обсудить проект» + «бесплатный аудит».
5. Кейсы — «Как мы автоматизировали производство и что это дало»; кейсы
   «Задача→Решение→Результат», отрасли и бренды кейса; CTA «Обсудить ваш проект».

## 7. Реализация и проверка

1. Изучить `instrument` (визитка, презентация) → палитра/подпись, «Наши бренды».
2. Скачать логотипы → `backend/email_templates/logos/`.
3. Дизайн-скелет + подпись.
4. Переписать 5 шаблонов (сохранить `{{ плейсхолдеры }}` и Jinja2).
5. Обновить БД: доработать `seed_templates.py` для обновления html стандартных
   шаблонов (чтобы пользователи увидели новые версии).
6. Проверка рендера/отправки в dev; релиз через автообновление.

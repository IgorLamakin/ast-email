## v2.5.0

- **Безопасность**: устранена критическая уязвимость рендера шаблонов (SSTI → RCE) —
  теперь письма рендерятся без исполнения произвольного кода, все значения
  экранируются.
- **Безопасность Electron**: окна переведены на `nodeIntegration:false`,
  `contextIsolation:true`, рендерер общается с главным процессом только через
  ограниченный мост `window.astAPI`. Предпросмотр письма — в `sandbox`-iframe.
- **Загрузки**: закрыт обход пути (`../`) и доступ без авторизации; лимит 20 МБ и
  белый список расширений; добавлено удаление файлов (`DELETE /files/{id}`).
- **Почта**: адрес отправителя (From) теперь всегда из настроек SMTP — меньше
  отказов от Яндекс/Mail.ru/Gmail.
- **Стандартные шаблоны**: больше не затираются при каждом запуске (синхронизация
  один раз при смене версии); убраны Jinja-условия, сайт нормализуется к https.
- **База**: логи отправок сохраняются компактно (без base64) — БД не разрастается.
- Backend при прямом запуске слушает только `127.0.0.1`.

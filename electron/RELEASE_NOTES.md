# Что нового

## v2.4.0

- **Обновлены все 5 стандартных шаблонов писем** — единый дизайн в фирменных
  цветах (светло-серый + зелёный), структура под получение заявок:
  - «Комплексная автоматизация производства» (общий обзор);
  - «Поставка КИПиА и АСУТП» — с категориями оборудования и «КП за 24 часа»;
  - «Шкафы управления под ключ» — ШУ/ШР/ЩА и «бесплатный 3D-проект»;
  - «Инжиниринг и разработка ПО» — SCADA, платформы, этапы «под ключ»;
  - «Реализованные проекты» — кейсы «Задача → Решение → Результат».
- В каждом письме: блок **«Наши бренды»** и **«Дополнительные бренды под
  заказ»**, CTA-кнопка с предзаполненной темой письма, подпись по визитке.
- Бэкенд при старте теперь **обновляет** содержимое стандартных шаблонов у
  уже зарегистрированных пользователей (не только добавляет отсутствующие).

## v2.3.2

- Исправление: окно «Доступна новая версия» больше нельзя сломать кнопками
  (исправлена политика безопасности, блокировавшая обработку нажатий
  «Установить обновление» / «Пропустить»).

## v2.3.1

- Служебный релиз (проверка механизма обновления).

## v2.3.0

- **Блочный редактор**: добавлена прозрачность блока (слайдер 10–100%).
- **Блочный редактор**: изображение можно изменить по размеру мышкой за угол,
  с привязкой к сетке 25/50/75/100%.
- **Блочный редактор**: границу между колонками теперь можно перетаскивать —
  задавайте пропорции (например, 30/70 вместо равных).
- Стабильность: исправлены ошибки обновления старых баз SQLite, устойчивость
  при чтении повреждённых файлов, отображение ошибок авторизации.
- **Автообновление**: при выходе новой версии приложение предложит обновиться
  само или позже из личного кабинета. Шаблоны, контакты и история сохраняются.

в CHANGELOG.md._

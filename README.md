# АСТ Email Templates

Система управления email-шаблонами для ООО "АСТ".

## Возможности

- **Блочный редактор шаблонов** — собирайте письма из готовых блоков (заголовок, текст, изображение, список, кнопка, инфографика, подпись, разделитель)
- **Drag & Drop** — перетаскивайте блоки мышью для изменения порядка
- **Стилизация блоков** — меняйте цвета фона, текста, отступы и выравнивание для каждого блока отдельно
- **Загрузка файлов** — прикрепляйте изображения и документы к шаблонам
- **Отправка писем** — отправляйте шаблоны на email с автосохранением контактов
- **Аналитика** — просматривайте историю отправок (для администратора)
- **Десктопное приложение** — работайте без браузера, как с обычной программой

## Запуск в режиме разработки

### 1. Backend

```bash
cd backend
py -3.12 -m uvicorn main:root_app
```

### 2. Frontend

```bash
cd frontend
npm run dev
```

Откройте http://localhost:3000

## Сборка десктопного приложения

### Требования

- Node.js 18+
- Python 3.12+ (только для сборки backend)
- PyInstaller (`py -3.12 -m pip install --user pyinstaller`)
- Windows 10/11

### Шаги сборки

1. Установите зависимости фронтенда:
   ```bash
   cd frontend
   npm install
   ```

2. Запустите сборку (она сама соберёт автономный backend и Electron):
   ```bash
   build-electron.bat
   ```

3. Установщик `.exe` появится в папке `dist-electron/`.

## Первая установка (для пользователей)

**Python пользователю не нужен** — backend входит в установщик как
`ast-backend.exe`.

1. Запустите установщик `AST Email Templates Setup.exe`
2. При первом запуске откроется мастер настройки:
   - Создайте аккаунт администратора
   - Настройте почту для отправки (SMTP)
3. После настройки приложение запомнит все параметры
4. При повторных запусках — сразу рабочее окно
5. Первый запуск может занять 1–2 минуты — дождитесь окна настройки

## Настройка SMTP

Для Яндекс Почты:
1. Зайдите на https://id.yandex.ru/security
2. Включите "Двухфакторная аутентификация"
3. Создайте "Пароль приложения" для типа "Почта"
4. Используйте этот пароль в настройках (не обычный пароль!)

## Тесты

```bash
py -3.12 -m pip install -r backend/requirements-dev.txt
py -3.12 -m pytest
```

Покрыты критичные сценарии: сохранение загруженных файлов, запрет опасных
расширений, отсутствие дубликатов стандартных шаблонов, корректность счётчиков
отправок.
